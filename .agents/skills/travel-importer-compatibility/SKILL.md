# 🚀 Travel Importer Compatibility: Стандарты Совместимости с Obsidian-Importer

Этот навык обучает агента создавать и проверять тревел-заметки Obsidian так, чтобы они **без единой ошибки и с максимальным обогащением данных** импортировались в веб-платформу Trip Scheduler через `tools/obsidian-importer`.

---

## 🧭 Ключевые требования obsidian-importer к структуре

Парсер `obsidian-importer` ожидает строго выверенную таксономию:

```text
-- <Название Путешествия>/
├── <Название Путешествия>.md           # Корневой хаб: title, краткое описание, даты
├── 02 - Маршрутный план/
│   ├── Маршрутный план.md              # Сводка маршрута
│   ├── 01 <Город> (<дн>) ...md         # Дневной файл
│   └── 02 <Город> (<дн>) ...md
├── 03 - Бронирования/
│   ├── Отели.md                        # Таблица броней отелей и каталог
│   ├── Авиаперелеты.md                 # Hero-коллаут, сегменты перелетов, Mermaid TD
│   └── Транспорт.md                    # Таблица трансферов/поездов, Mermaid flowchart
├── 04 - Финансы/
│   └── Финансы.md                      # Смета с категориями ✈️, 🚗, 🏨, 🍜, 🎟️, 🎁
├── 05 - Полезная информация/
│   └── Полезная информация.md
├── 06 - Чек лист/
│   ├── Чек лист.md                  # Хаб чек-листов
│   ├── Чек-лист подготовки и сборов.md # Документы, IT, аптечка, гардероб
│   └── Что попробовать и купить (Must-Try & Must-Buy).md
└── _/                                  # Вложения
    ├── 01/                             # Фотографии для дня 01
    └── PrivateDocuments/               # Личные документы путешествия (маршрут-квитанции, билеты, полисы)
```

---

## 🎯 1. Главный Хаб `<Название>.md`

Парсер извлекает:
1. **Название тура:** берется из заголовка `# <Название>` или имени файла.
2. **Краткое описание (descriptionShort):** извлекается строго из раздела:
   ```markdown
   ## 📝 Краткое описание
   Емкий абзац текста на 2–4 предложения. Обязателен заголовок именно с эмодзи 📝 или текстом "Краткое описание".
   ```
3. **Города и даты:** распознаются из таблицы мастер-плана и имен файлов `02 - Маршрутный план/`.

---
   
## 📅 2. Дневные заметки (`02 - Маршрутный план/*`)

### А. Заголовок и метаданные дня:
```markdown
# 🗓️ День 01: Суббота (🌴 Отпуск)

> **Локация:** Тайбэй.
> **Фаза тура:** 100% Отпуск. Погружение в колорит старого города.
> **Проживание:** Morwing Hotel, ~3 200 ₽ / ночь.
> **Ключевой хайлайт:** Неоновые огни Taipei 101 и стритфуд рынка Раохэ.
```
> [!IMPORTANT]
> `> **Фаза тура:**` и `> **Ключевой хайлайт:**` автоматически склеиваются парсером в поле `day.description`!

### Б. Подготовка и Бейджи (`day.meta`):
Любые коллауты в блоке до первой активности парсер преобразует в интерактивные чипы `day.meta`:
* `> [!IMPORTANT]` — системные требования (билеты, брони).
* `> [!CAUTION]` / `> [!WARNING]` — штрафы, безопасность, запреты.
* `> [!TIP]` — полезные советы.

**Ключевые слова для иконок бейджей:**
* `лотерея` / `lucky` / `приз` ➔ `mdi:gift-outline` (золотистый)
* `велосипед` / `youbike` ➔ `mdi:bike`
* `миграционная` / `twac` / `запрет` / `штраф` ➔ `mdi:alert-octagon-outline` (красный)
* `метро` / `поезд` / `mrt` / `thsr` / `tra` ➔ `mdi:subway-variant`
* `онсэн` / `термальные` ➔ `mdi:hot-tub`
* `дождь` / `погода` ➔ `mdi:weather-rainy`
* `черепахи` / `кораллы` ➔ `mdi:turtle` (зеленый)
* `аптечка` / `лекарства` ➔ `mdi:pill`
* `чай` / `еда` / `ланч` ➔ `mdi:food`

### В. Активности и Таймлайн:
Формат строки времени строго обязателен:
```markdown
* **09:30 - 11:30** — **Название активности (Локация)**:
    * *Контекст*: Историко-культурная справка.
    * *Маршрут*: Инструкции по проезду.
    * _Ссылка на локацию_: [Google Maps: Название](https://maps.google.com/?q=Запрос)<iframe src="https://maps.google.com/maps?q=Запрос&output=embed" style="width: 100%; min-width: 100%; height: 350px; display: block; border: 0; border-radius: 8px; margin-top: 10px; margin-bottom: 15px;" loading="lazy"></iframe>

> [!TIP]
> Локальный совет к этой активности.

> [!INFO]- Картинки
> ![[фото.jpg]]
```
* Время: **двузначные часы и минуты** через двоеточие: `09:30 - 11:30` (не `9:30`, не `09.30`).
* Автоматическая классификация тегов:
  - `transport`: перелет, поезд, метро, mrt, thsr, tra, трансфер, grab, uber, автобус, паром.
  - `food`: завтрак, обед, ужин, стритфуд, кофе, чай, ресторан, кафе, рынок.
  - `walk`: прогулка, хайкинг, пешком, подъем, треккинг, набережная, тропа.
  - `attraction`: храм, музей, небоскреб, мемориал, водопад, смотровая, парк.
  - `relax`: отель, заселение, бассейн, пляж, онсэн, спа, отдых.

### Г. Посуточные финансы:
В конце дневного файла:
```markdown
## 💰 Финансовые затраты на день (на 1 чел)
* Транспорт: `~250 ₽`.
* Еда: `~1 200 ₽`.
* **Итого за день (без отеля):** около `~1 450 ₽`.
```

## 🏨 3. Бронирования (`03 - Бронирования/*`)

### `Отели.md`:
1. Сводная таблица обязательна:
   ```markdown
   | Ночи | Локация | Отель №1 (Основной выбор) | Ночей | Цена / ночь | Локация отеля | Итого за локацию |
   |:---:|:---|:---|:---:|:---:|:---|:---:|
   | 01–04 | Тайбэй | [Morwing Hotel Fairy Tale](https://www.trip.com/w/...) | 3 | 3 200 ₽ | [Google Maps](https://maps.google.com/?q=25.0460915,121.5134522) | 9 600 ₽ |
   ```
2. Подробные секции каталога с характеристиками и фото:
   ```markdown
   ### 🏙️ Тайбэй (Ночи 01–04)
   * **№1 (Основной выбор):** [Morwing Hotel](https://...)
     * *Особенности:* Wi-Fi 250 Мбит/с, рабочий стол, 3 мин от станции MRT.
     * *Фото:* ![[Morwing_Hotel_1.jpg]], ![[Morwing_Hotel_2.jpg]]
   ```
   Либо через коллаут картинок под отелем:
   ```markdown
   > [!INFO]- Картинки
   > ![[Morwing_Hotel_1.jpg]]
   > ![[Morwing_Hotel_2.jpg]]
   ```
   > [!TIP]
   > При импорте `obsidian-importer` автоматически находит изображения по именам в вольте через `buildImageIndex`, загружает их на сервер и прикрепляет к карточке бронирования отеля (`Booking.data.photos`). В карточке бронирования в Trip Scheduler отображается интерактивная фотогалерея.

### `Авиаперелеты.md`:
* Hero Callout:
  ```markdown
  > [!SUCCESS]+ 🥇 Выбранный авиаперелет: **China Eastern Airlines** (~58 000 ₽ туда-обратно)
  ```
* Таблица сегментов с датами, номерами рейсов, вылетом и прилетом.

### `Транспорт.md`:
Сводная таблица логистики (формат — в скилле `travel-logistics-and-budget`, раздел `Транспорт.md`):
```markdown
| День | Сегмент | Транспорт | Время в пути | Способ бронирования / Оплата |
|:---:|:---|:---|:---:|:---|
| **01** | Тайбэй ➔ Цзяи | 🚄 THSR (скоростной поезд) | 1 ч 30 мин | Trip.com — 4 200 ₽ |
| **03** | Цзяи ➔ Алишань | 🚌 Горный автобус | 2 ч 30 мин | На месте — 250 TWD |
| **05** | Тайнань ➔ Люцю | ⛴ Паром | 1 ч 10 мин | Официальный сайт — 400 TWD |
```

Импортер раскладывает строки таблицы по разделам платформы и ставит пометку по колонке `Транспорт`:

| Раздел платформы | Слова в колонке `Транспорт` |
|:---|:---|
| **Поезда** | «поезд», «TRA», «EMU», «метро», «MRT»; «THSR»/«скоростной» |
| **Авто** (теги: Такси, Трансфер, Авто с водителем, Аренда авто, Личное авто, Автобус, Вело / мото) | «такси»/«Яндекс Go»/«Grab», «трансфер», «с водителем», «аренда»/«прокат», «личное авто»/«машина», «автобус»/«шаттл», «мотоцикл»/«скутер»/«мопед» |
| **Другое** (теги: Паром, Катер , Канатная дорога, Вело , Пеший переход, Прочее) | «паром»/«корабль», «катер»/«лодка», «канатная дорога»/«фуникулёр»/«подъёмник», «велосипед»/«электровелосипед»/«самокат», «пешком» |

* Не бывает «просто поездки»: если в колонке нет опознаваемого слова, запись уходит в «Другое» с пометкой «Прочее» — пишите вид транспорта словами.
* Водный транспорт, подъёмники, велосипед и пешие переходы — это **не** «Авто» и **не** «Поезда»: они всегда попадают в «Другое».
* `Автобус` относится к «Авто» (горный автобус, шаттл, городской автобус), а не к «Другое».

## 💰 4. Финансы (`04 - Финансы/Финансы.md`)

Разделы с обязательными иконками для автоматического сопоставления категорий:
* `### ✈️ 1. Международный авиаперелет` ➔ категория `Авиабилеты` (`cat-flights`)
* `### 🚄 2. Поезда и междугородний транспорт` ➔ категория `Транспорт` (`cat-transport`)
* `### 🏨 3. Проживание (Отели)` ➔ категория `Жильё` (`cat-housing`)
* `### 🍜 4. Питание и стритфуд` ➔ категория `Еда и напитки` (`cat-food`)
* `### 🎟️ 5. Входные билеты и активности` ➔ категория `Развлечения` (`cat-entertainment`)
* `### 🎁 6. Сувениры, чай и подарки` ➔ категория `Покупки` (`cat-shopping`)
* `### 📱 7. Связь, страховка и интернет` ➔ категория `Связь и страховка` (`cat-telecom`)

Каждая строка таблицы парсится в транзакцию:
```markdown
| Статья расхода | Стоимость в ₽ | Примечание |
| :--- | :---: | :--- |
| Билеты на скоростной поезд THSR | 4 200 ₽ | Тайбэй ➔ Гаосюн |
```

### Поддержка «План / Факт» (Plan vs Fact):
* **Бюджет поездки (`trip.budget`) и лимиты категорий (`budgetLimit`):**
  Парсер извлекает общий бюджет из Hero Callout `[!summary]+` (например, `💰 Общий бюджет поездки: **~201 763 ₽**`) и построчно проставляет плановые лимиты по категориям.
* **Статусы транзакций (`status: 'paid' | 'planned'`):**
  - Предоплаченные отели и купленные авиабилеты маркируются статусом `paid`. В `Отели.md` или `Финансы.md` признаком оплаты служит пометка `*(оплачено)*` в строке или названии.
  - Дискретные предстоящие расходы (неоплаченные отели, билеты на поезда THSR/TRA, паромы, автотрансферы, виза, входные билеты в парки) импортируются как отдельные строки со статусом `planned` и точными календарными датами (на основе дней маршрута).
  - Потоковые карманные расходы (ежедневное питание, сувениры и общий буфер) задаются целевым лимитом категории (`budgetLimit`) без создания фантомных транзакций-монолитов, предотвращая задвоение трат при внесении чеков в поездке.
  - Предотвращается двойной учет: если есть подробные таблицы сегментов, суммарные строки-подитоги игнорируются в пользу индивидуальных броней.

## ✅ 5. Чек-листы (`06 - Чек лист/*`)

В файле `Что попробовать и купить (Must-Try & Must-Buy).md`:
```markdown
### 🏮 1. Легендарный стритфуд ночных рынков
- [ ] **Сяолунбао (Soup Dumplings)** — Тончайшее тесто с горячим бульоном. *(💰 ~150 TWD)*. *Локация:* [Din Tai Fung](https://maps.google.com/...)
```
* Стоимость в скобках `*(💰 ~150 TWD)*` или `*(~500 ₽)*` автоматически извлекается в поле `cost`.
* Локация `*Локация:* ...` или `*Где пробовать:* ...` автоматически извлекается в поле `location`.
* Ссылка `[...]` извлекается в поле `link`.

## 📁 6. Документы поездки (`PrivateDocuments` и `PublicDocuments`)

Парсер `obsidian-importer` автоматически обнаруживает директории с документами (как в `_/`, так и в корне путешествия):
* **Личные документы (`PrivateDocuments`, `PrivateDocument`, `Личные документы`):**
  Все файлы загружаются со статусом `access: 'private'` — доступ открыт только владельцу и участникам с правами.
* **Публичные / общие документы (`PublicDocuments`, `PublicDocument`, `Общие документы`, `Documents`):**
  Все файлы загружаются со статусом `access: 'public'` — видны всем зрителям поездки.
* **Автоматическая категоризация:**
  Имена файлов и названия подпапок сопоставляются с категориями Trip Scheduler:
  - `tickets`: маршрут-квитанции, билеты, посадочные талоны (`Эл. маршрут-квитанция.pdf`, `ticket.pdf`)
  - `id`: паспорта, визы, водительские удостоверения (`Паспорт.pdf`, `visa.png`)
  - `transport`: ж/д билеты, трансферы, паромы (`THSR_Train_Booking.pdf`, `bus.pdf`)
  - `lodging`: подтверждения отелей и ваучеры проживания (`Hotel_Confirmation.pdf`)
  - `insurance`: полисы медицинского страхования (`Полис_Тинькофф.pdf`)
  - `other`: памятки, гайды, общие материалы
* **Структура папок:** Подпапки внутри директорий (например, `_/PrivateDocuments/Билеты/` или `PublicDocument/Инструкции/`) автоматически регистрируются и создаются в разделе «Документы» Trip Scheduler.

## 🔎 Чек-лист самопроверки перед импортом
1. [ ] Имя корневой папки начинается с `-- ` (или выбрано явно через `-d`).
2. [ ] В корне лежит `<Название>.md` с разделом `## 📝 Краткое описание`.
3. [ ] В дневных файлах тайминги активностей имеют формат `* **HH:MM - HH:MM** — **Заголовок**:`.
4. [ ] Все Google Maps имеют responsive iframe `style="width: 100%; min-width: 100%; height: 350px; display: block; border: 0; border-radius: 8px; margin-top: 10px; margin-bottom: 15px;" loading="lazy"`.
5. [ ] В `Отели.md` есть сводная таблица с колонками `| Ночи | Локация | Отель ... |`.
6. [ ] В `Финансы.md` заголовки содержат эмодзи ✈️, 🚄, 🏨, 🍜, 🎟️, 🎁.
7. [ ] В `Транспорт.md` в колонке `Транспорт` у каждой строки есть однозначное слово (такси, трансфер, аренда, автобус, паром, канатная дорога, велосипед) — иначе запись уйдёт в «Другое» без пометки.
8. [ ] Документы поездки разложены по `_/PrivateDocuments` (личные/закрытые) и `_/PublicDocuments` (публичные/общие) для удобной загрузки в раздел документов.
