- `geo:backfill-cities audit`: 59 items; по поездкам (trips) — **0** (города поездок уже были связаны либо отсутствовали).

## Apply

- `apply --apply`: `resolved 24 / selected 24 / applied 24`, одной транзакцией.
- Кросс-страна: у 23 записей (22 highlight + 1 destination_review) `countryId` исправлен Китай (`eef83859-…`) → Гонконг (`b9d57a3f-…`) — ручной `reviewed_mapping` разрешает смену страны и приводит `countryId` записи к стране выбранного места. ## Runbook

```
bun run geo:import --data-dir=/tmp/geonames [--apply]
bun run geo:backfill-cities audit --output <private>.json
# review needs_review, затем
bun run geo:backfill-cities apply --mapping <private>.json [--apply]
bun run geo:backfill-cities status [--run-id <id>]
bun run geo:backfill-cities rollback --run-id <id> [--apply]
bun run geo:cleanup-trip-cities audit --output <private>.json
bun run geo:cleanup-trip-cities apply --mapping <private>.json [--apply]
```

Все команды без `--apply` — dry-run. Манифесты приватные (mode 0600), держать вне git и вне эфемерного `/tmp` контейнера.
