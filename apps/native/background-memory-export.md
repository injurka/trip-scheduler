# Проверка фонового скачивания воспоминаний на Android

Вся очередь передаётся `MemoryExportService` одной командой. Foreground service
типа `dataSync` хранит прогресс независимо от Activity/WebView. Уведомление
показывает количество обработанных файлов, сохранённых, пропущенных и ошибок.
Повторное скачивание проверяет наличие файлов до обращения к сети.

## Проверка на устройстве

1. На Android 13+ запретить уведомления, нажать скачивание дня. Ожидается
   объяснение необходимости разрешения; кнопка не остаётся заблокированной.
2. Разрешить уведомления, выбрать день с несколькими большими файлами и начать
   скачивание. Свернуть приложение до окончания первого файла. В уведомлении
   должен увеличиваться прогресс всей очереди, включая последующие файлы.
3. Заблокировать экран, дождаться окончания. Уведомление должно показать итог;
   готовые файлы находятся в `Downloads/TripScheduler`.
4. Вернуться в приложение, переключить день и вернуться назад. UI должен читать
   состояние сервиса. Повторное скачивание пропускает уже сохранённые файлы.
5. Во время скачивания нажать «Остановить» в уведомлении. Новые файлы не
   запускаются, незавершённый файл удаляется, готовые сохраняются. При повторной
   попытке скачиваются оставшиеся файлы.
6. Прервать сеть во время большого файла, затем вернуть её и повторить
   скачивание. Ошибка одного файла не блокирует остальные; недокачанный файл не
   считается сохранённым.
7. На Android 9 проверить запрос разрешения записи и отказ от него. На Android
   10+ проверить видимость файлов через MediaStore. На Android 15+ проверить
   обработку ограничения времени `dataSync` через тестовые настройки Android.

Принудительная остановка приложения в настройках Android и завершение процесса
останавливают сервис. Очередь не восстанавливается после перезагрузки/force-stop;
пользователь может повторить скачивание дня, готовые файлы будут пропущены.

## Автоматические проверки

- `apps/client`: `vitest run --config test/memory-export.vitest.config.ts` —
  передача всего дня, блокировка повторного клика, разрешения, отмена,
  восстановление UI и ошибки нативного сервиса.
- Android JVM: `MemoryExportQueueTest` — сохранение всей очереди, пропуск
  существующего файла, продолжение после ошибки и отмена в процессе чтения.

JVM-проверки не заменяют проверку уведомлений и жизненного цикла на устройстве.

Android: [тип dataSync](https://developer.android.com/develop/background-work/services/fgs/service-types#data-sync),
[обработка тайм-аута](https://developer.android.com/develop/background-work/services/fgs/timeout).
