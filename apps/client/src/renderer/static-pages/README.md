# Статические страницы

`pages.json` задаёт публичные адреса, компоненты, заголовки и необходимость гидратации.
Сборка `build/lib/static-pages.ts` рендерит HTML и собирает ресурсы отдельно от SPA.
Роутер и service worker используют тот же реестр. В Tauri сохраняются обычные Vue-маршруты.

Для новой страницы:

1. Добавить независимый компонент в `components/05.modules`.
2. Создать папку `<slug>` с `index.html` и `main.ts` по существующему образцу.
3. Добавить запись в реестр и обычный Vue-маршрут для разработки и Tauri.

Компонент получает `standalone: true`. В этом режиме навигация должна работать обычными
ссылками без авторизации, API и глобальных сервисов приложения. При `hydrate: false`
HTML сохраняет CSS, но не загружает JavaScript. Интерактивность требует `hydrate: true`.
