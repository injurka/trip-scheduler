# Каталоги метро

## Тайвань

Снимок проверен 21 октября 2026 года: шесть линий BR/R/G/O/BL/Y,
136 станционных кодов (пересадочные станции имеют отдельные коды линий).
Девять записей направлений: две ветки O, отдельно Xinbeitou и Xiaobitan.
Красная линия включает открытую в 2026 году R01 Guangci/Fengtian Temple.
Airport MRT, Danhai, Ankeng и Sanying — отдельные сети операторов и сюда не входят.

## Источники

- Актуальные коды и английские имена: [официальная интерактивная схема](https://web.metro.taipei/pages/en/roadmap/station), [страница оператора](https://english.metro.taipei/cp.aspx?n=1BE0AF76C79F9A38).
- Координаты пяти основных линий: [открытый GeoJSON справочник](https://github.com/3cmFatHome/taipei-metro-stations/blob/master/taipei.json), основанный на данных Taipei Metro. Список старый; названия/полнота сверены с текущей официальной схемой, R01 добавлена отдельно.
- Координаты Circular: [GIS муниципального бюро метро](https://data.taipei/dataset/detail?id=758e5ae0-e6ee-448b-81f5-316eb68a5ba7), [JSON](https://data.taipei/api/frontstage/tpeod/dataset/resource.download?rid=a63e3278-9d10-4916-9f24-e5a4d78afb31). Преобразованы из EPSG:3826 (TWD97 / TM2 zone 121, GRS80) в WGS84; точность до шести знаков. Это точки станций, не выходов.
- R01: код/название из текущей официальной схемы, [координаты](https://zh.wikipedia.org/zh-hant/廣慈/奉天宮站) 25.03747, 121.58188.
- Цвета BR #C48C31, R #E3002C, G #008659, O #F8B61C, BL #0070BD, Y #FFDB00; маршрут соединяет станции отрезками, геометрию тоннелей не воспроизводит.

Файл `data/taipei.json` — готовый запрос существующего `/metro/import`.
ID стабильны и имеют префикс `tw-taipei-`; повторная загрузка обновляет каталог.

## Загрузка

Из корня репозитория:

```bash
bun tools/metro-import/import.ts
```

## Проверка скрипта

```bash
bun --filter @injurka/metro-import lint
bun --filter @injurka/metro-import typecheck
```

Для записи задайте переменные `METRO_API_URL`, `METRO_EMAIL`, `METRO_PASSWORD`
и выполните `bun tools/metro-import/import.ts --apply`. Пароль/токен скрипт не выводит.
URL — корень API, без `/trpc`.

Скрипт входит, загружает каталог и читает его обратно, проверяя линии и порядок
станций. Старый API примет названия/цвета/порядок, но отбросит координаты;
скрипт явно сообщит об этом.

Для карты разверните новый сервер и клиент. Сервер при старте автоматически
применяет миграции, включая `0011_funny_sunset_bain.sql` с nullable-координатами.
Затем повторите импорт той же командой: старые города совместимы, но карта
доступна только для линий с координатами всех станций. В блоке активности
выберите «По городу» → «Тайбэй» → «Просмотр на карте».

Автоматического обновления расписаний, расчёта тарифов, оптимального поиска
пересадок или проверки оперативных закрытий здесь нет. Направление определяется
по конечной выбранной ветки; фактический поезд может выполнять укороченный рейс.

## Гаосюн и Тайчжун

Проверено 21 октября 2026 года:

| Каталог                   | Линии                                            | Станционные коды  |
| ------------------------- | ------------------------------------------------ | ----------------- |
| `kaohsiung.json` — Гаосюн | R Red Line, O Orange Line, C Circular Light Rail | 25 + 14 + 38 = 77 |
| `taichung.json` — Тайчжун | G Green Line                                     | 18                |

Пересадочная Formosa Boulevard имеет два кода R10/O5. В Гаосюн включена
действующая станция RK1 Gangshan; строящиеся продления не включены. O1 имеет
актуальное имя Hamasen и прежний вариант Sizihwan для совместимости заметок.
Нумерация оранжевой линии пропускает O3: O1 → O5 означает 3, а не 4 остановки.

В Тайчжуне основные коды — пассажирские `103a`, `103`–`119`, сверенные с
официальной схемой. В названия добавлены также коды исходного CSV (`G0`, `G3`,
`G8a` и др.). Исходный CSV дважды использует G17, для Wuri и HSR Taichung. Этот
неоднозначный псевдоним исключён из каталога; используйте пассажирские 118 и 119.

### Загрузка выбранного города

```bash
bun tools/metro-import/import.ts --city kaohsiung
bun tools/metro-import/import.ts --city taichung
bun tools/metro-import/import.ts --city moscow
# Все каталоги:
bun tools/metro-import/import.ts --all
```

Добавьте `--apply` и переменные окружения из инструкции выше для записи на сервер.
Без `--city` сохранено прежнее поведение: выбирается Тайбэй.
Скрипт проверяет порядок/цвета линий и сообщает, сколько координат сервер
действительно сохранил, а также сохранился ли признак кольцевой линии.

Для C добавлено поле `isCircular` и миграция `0012_sticky_professor_monster.sql`.
Новый клиент замыкает линию на карте и выбирает кратчайшую дугу между станциями;
importer считает остановки так же. После обновления сервера требуется повторить
импорт каталога, чтобы записать `isCircular: true`. Это не расписание. Если в исходном блоке уже задано направление движения
по кольцу, importer сохраняет ручной ввод, чтобы не заменить выбранную дугу кратчайшей.

Importer распознаёт Гаосюн/Kaohsiung/高雄 и Тайчжун/Taichung/台中/臺中,
поддерживает числовые пассажирские коды. При конфликте названия и кода
(например, `Daqing (110)` вместо 115 или `Nantun (110)` вместо 113) блок
остаётся ручным: importer не подменяет пункт назначения на Taichung City Hall.
